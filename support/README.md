# راه‌اندازی گفتگوی پشتیبانی کشت‌آذر با روبیکا

پنل، گفتگوها و پیام‌ها را در پایگاه‌دادهٔ سایت ذخیره می‌کند. هر گفتگوی بازدیدکننده با کد اختصاصی خودش به حساب پشتیبانی روبیکا وصل می‌شود. پاسخ مدیر از روبیکا با قابلیت Reply روی اعلان همان پیام به گفتگوی درست برمی‌گردد. تاریخچهٔ گفتگوها در Django Admin قابل مشاهده است.

## تنظیم بات و حساب پشتیبانی

1. در روبیکا با `@BotFather` یک بات بسازید. توکن بات را فقط در متغیر محیطی سرور با نام `SUPPORT_RUBIKA_BOT_TOKEN` قرار دهید؛ آن را در کد، مخزن یا گفتگوها قرار ندهید.
2. در محیط سرور، `SUPPORT_RUBIKA_ENABLED=False` بماند. سپس دستور زیر را اجرا کنید:

   ```sh
   python manage.py discover_support_rubika_chat
   ```

   وقتی دستور خواست، با همان حساب روبیکایی که برای پشتیبانی شمارهٔ `09138825163` استفاده می‌کند، بات را باز کنید و `/start` بفرستید. دستور دو مقدار `SUPPORT_RUBIKA_CHAT_ID` و `SUPPORT_RUBIKA_USER_ID` را چاپ می‌کند. هر دو را در متغیرهای محیطی سرور ذخیره کنید. این شناسه‌ها با شمارهٔ تلفن فرق دارند.

3. یک راز URL-safe بسازید و خروجی را به‌عنوان `SUPPORT_RUBIKA_WEBHOOK_SECRET` در محیط سرور قرار دهید:

   ```sh
   python -c "import secrets; print(secrets.token_urlsafe(32))"
   ```

4. مقدار `SUPPORT_PUBLIC_URL` را روی دامنهٔ عمومی HTTPS سایت، مانند `https://keshtazar.ir`، بگذارید. هنوز `SUPPORT_RUBIKA_ENABLED=False` باشد.
5. migrationها را روی پایگاه‌دادهٔ مقصد اجرا کنید و سپس وب‌هوک را ثبت کنید:

   ```sh
   python manage.py migrate --noinput
   python manage.py configure_support_rubika_webhook
   ```

   دستور ثبت وب‌هوک، شناسهٔ چت خصوصی را با بات بررسی می‌کند و فقط روی دامنهٔ عمومی HTTPS کار می‌کند. پس از پیام موفقیت، `SUPPORT_RUBIKA_ENABLED=True` کنید و برنامهٔ Django را از نو راه‌اندازی کنید.

## پاسخ دادن به پیام‌ها

هر پیام سایت به‌صورت اعلان جداگانه با کد گفتگو برای حساب پشتیبانی فرستاده می‌شود. در روبیکا روی همان اعلان، قابلیت Reply را بزنید و پاسخ را ارسال کنید. وب‌هوک پاسخ را با پیام اصلی تطبیق می‌دهد و در پنل بازدیدکننده نشان می‌دهد. پاسخ به‌صورت پیام عادی و بدون Reply به گفتگو متصل نمی‌شود.

گفتگوها و وضعیت تحویل اعلان در Django Admin قابل بررسی هستند. شمارهٔ `SUPPORT_PHONE` فقط پیوند تماس تلفنی داخل پنل است؛ اتصال پیام‌ها به روبیکا با شناسه‌های چت و حساب انجام می‌شود.

## متغیرهای محیطی

```text
SUPPORT_PHONE=09138825163
SUPPORT_RUBIKA_ENABLED=False
SUPPORT_RUBIKA_BOT_TOKEN=
SUPPORT_RUBIKA_CHAT_ID=
SUPPORT_RUBIKA_USER_ID=
SUPPORT_RUBIKA_WEBHOOK_SECRET=
SUPPORT_PUBLIC_URL=https://keshtazar.ir
```

مقادیر خالی را پس از اجرای مرحله‌های بالا در محیط سرور تنظیم کنید. توکن واقعی بات را داخل این فایل نمونه ننویسید.
